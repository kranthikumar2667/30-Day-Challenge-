1. This program is a simple Seat Booking System written in C.
2. It uses a 2D array to represent seats.
3. The system contains 5 rows and 8 seats in each row.
4. It allows users to book available seats.
5. Users can cancel their booked seats.
6. It also supports group seat reservations.
7. The program checks seat availability before booking.
8. It prevents invalid seat numbers and group sizes.
9. It displays the total booked and available seats.
10. A menu-driven approach makes the program easy to use.
