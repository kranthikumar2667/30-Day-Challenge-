this is challenge 08 of 30-day challenge
a small briefing about code : 
1. The program accepts the grid size between 3 and 6.
2. It reads risk scores between 0 and 100 for each cell.
3. It accepts a threshold value between 1 and 100.
4. It finds the highest risk score and its positions.
5. It calculates the total of each row and identifies the highest row total.
6. It calculates the total of each column and identifies the highest column total.
7. It calculates the main and secondary diagonal sums and compares them.
8. It calculates the total risk score along the boundary of the grid.
9. It counts cells meeting the threshold and identifies local hotspots.
10. Finally, it displays the results and gives a CRITICAL or NORMAL decision.
