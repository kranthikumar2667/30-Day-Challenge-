1. The Expense Management System is a C program used to record and analyze expenses entered by the user.
2. It accepts expense amounts continuously until the user enters 0 to terminate the program.
3. Negative expense amounts are considered invalid and are not included in the calculations.
4. The program classifies expenses into three categories: small (less than 100), medium (100 to less than 500), and large (500 or more).
5. It calculates the number of valid expenses and the total amount spent in each category.
6. It calculates the total expenditure and the average expense of all valid entries.
7. The program uses variables, loops, conditional statements, and arithmetic operations to process expenses and display a summary report.
