This C program calculates the fuel expenses for a planned trip. It takes three inputs from the user:

Total distance of the trip in kilometres. Vehicle mileage in kilometres per litre. Petrol price per litre.

It then calculates:

Fuel required = Distance ÷ Mileage Total fuel cost = Fuel required × Petrol price

Finally, it displays the trip distance, amount of petrol required, and estimated fuel cost. i have uploaded my input as well as 3 different values
